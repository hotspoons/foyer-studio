How should Foyer run?

Pick once — saved to config.yaml. Re-run with --reset-mode to change later.

Host mode

Run Foyer directly on this machine

The native shell will embed foyer-server in this window and look for a local Ardour install (with the Foyer shim) to attach to. The checks below tell you what to install first.

Docker › Container runtime

Pick a container runtime

Foyer's backend runs inside a Linux container. Pick which container engine on this Mac/PC should host it. Greyed-out cards aren't installed yet — copy the install command, run it in a terminal, then hit Re-check.

Docker › Audio mode

Pick an audio integration

Each option's pre-flight check ran when the picker opened. Greyed-out modes are blocked by a missing dependency — copy the suggested install command, run it, then hit Re-check.

Docker › Networking

Choose a networking model

Host mode is lower latency and required for some discovery protocols, but only works on Linux — Docker Desktop's VM silently falls back to bridge. Bridge works everywhere.
