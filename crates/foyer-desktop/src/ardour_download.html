Download Ardour for macOS

Foyer's native-Ardour mode needs a local Ardour install. The community build is donationware — please consider supporting the project.

Ardour is donationware. Foyer Studio is a separate project that integrates with Ardour. The Ardour developers ask for a one-time $45 donation to support the engine you'll be using — donors receive a signed/notarized build with no 10-minute audio cutoff. The free demo IS fully functional (every feature works), but audio silences after ~10 minutes per launch as a nag. For production use we strongly recommend donating.
